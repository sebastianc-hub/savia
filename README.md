# Savia · página instalable

Cascarón público de **Savia** (Software by MÖÖna Technologies). Embebe el visor del paciente de cada clínica
(Apps Script) y aporta lo que Google no deja poner: el ícono de Savia al **agregar a la pantalla de inicio**
en iPhone y Android, modo app (sin barra del navegador) y un aviso de instalación.

Uso: `https://sebastianc-hub.github.io/savia/?a=<ID de implementación>&t=<token del paciente>`

- `a` = el ID que va en `https://script.google.com/macros/s/<ID>/exec`
- `t` = token del paciente (hoja Pacientes)

No guarda datos: solo arma la URL del visor y la muestra a pantalla completa.
